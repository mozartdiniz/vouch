# ds3-tools

Dark Souls 3 build optimization over a local ten-weapon dataset.

- Every number comes from data/weapons.csv, a simplified model of the game's scaling rather than a copy of its tables.
- Call weapon-lookup first whenever the user's weapon name is not the exact in-game spelling. stat-optimizer accepts exact names only and refuses anything else.
- More than one candidate from weapon-lookup is not a list to choose from. Ask the user which weapon they meant, and call stat-optimizer only once they have answered.
- No candidates from weapon-lookup means the weapon is outside this dataset. Say so; there is no stat spread to compute and no node that can produce one.

Call these with `vouch call <node> --input '{...}'`. The result is a JSON object on stdout.
Everything else — including the reason for any failure — goes to stderr.

Every call ends in one of three things, and they call for different responses:

- **exit 0** — the value satisfied the node's contracts. Use it. Do not recompute anything
  from it; quote its figures as they are.
- **exit 11, 14 or 15** — a refusal. No answer is available from this node. The reason is
  written to be acted on: fix the arguments, call a different node, or tell the user the
  answer does not exist. Never substitute your own number.
- **exit 10, 12, 13, 20 or 21** — a caller error or a broken node. Correct the input if it
  was rejected; otherwise report the node as broken rather than working around it.

A refusal is a good outcome when it is the true one. No answer beats a wrong one.

## stat-optimizer

Optimal stat allocation for a target weapon and soul level in Dark Souls 3

**Use when**

- the question names a specific weapon or build archetype
- the user asks what stats to level
- the user asks whether a build can wield a weapon at a given soul level

**Not for**

- item locations
- boss strategies
- lore questions
- resolving a partial or misspelled weapon name — call weapon-lookup first

**Parameters**

- `soul_level` (integer, required) — Target soul level. If the user does not say, assume 125.
- `weapon` (string, required) — Exact in-game weapon name, matching the spelling in the refusal message if you get one.

**Examples**

- "best stats for a Lothric Knight Sword build at SL120"
  ```
  vouch call stat-optimizer --input '{"soul_level":120,"weapon":"Lothric Knight Sword"}'
  ```
- "what should I level for a quality Zweihander build?"
  ```
  vouch call stat-optimizer --input '{"soul_level":125,"weapon":"Zweihander"}'
  ```

## weapon-lookup

Resolve a partial or misspelled weapon name to its exact Dark Souls 3 spelling

**Use when**

- the user names a weapon in anything but its exact in-game spelling
- stat-optimizer refused with an unknown-weapon message
- you need to know whether a weapon is in this collection's dataset at all

**Not for**

- stat allocation — call stat-optimizer with the name this node resolved
- choosing between candidates when this node reports more than one; that is the user's call
- weapons outside this collection's dataset
- item locations, boss strategies, lore questions

**Parameters**

- `query` (string, required) — The weapon name exactly as the user wrote it. Do not tidy it up or guess at a fuller name first — resolving it is this node's job, and a guess is the thing being prevented.

**Examples**

- "what should I level for a lothric sword build?"
  ```
  vouch call weapon-lookup --input '{"query":"lothric sword"}'
  ```
- "is the uchi worth using?"
  ```
  vouch call weapon-lookup --input '{"query":"uchi"}'
  ```
